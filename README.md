# Tender Agent Kazakhstan — стартовая версия

Веб-панель для ручного добавления тендеров и предварительного расчёта рентабельности.

## Развёртывание на Railway
Railway должен подключить этот GitHub-репозиторий и автоматически запустить команду из Procfile.

## Важно
Эта версия **не подключена к API тендерных площадок** и не ищет закупки автоматически. Для автоматического поиска потребуется официальный API/разрешённый источник и ключи доступа, которые нужно хранить в Railway Variables, а не отправлять в чат.

## Фильтры
- Регион: Караганда и Карагандинская область
- Максимальная сумма: 10 000 000 ₸
- Целевая рентабельность: 20%
- Лицензия: обязательное требование блокирует предварительный допуск
